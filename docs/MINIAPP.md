# Mini App — что сделано, как проверено, где границы

Веб-поверхность для «тяжёлого» UI: каталог, карточка лота с галереей, подбор по
цене, калькулятор доставки. Запускается из бота кнопкой «📱 Открыть приложение»
и отдельным адресом в браузере.

Скриншоты (390×844, реальный рендер): `docs/screens/catalog.png`,
`card.png`, `price.png`, `calc.png`.

---

## 1. Границы: что в Mini App, а что в чате

| Задача | Где живёт | Почему |
|---|---|---|
| Каталог, карточка, галерея | Mini App | тяжёлый UI: сетка спеков, свайп фото |
| Подбор по цене, фильтры | Mini App | формы и списки неудобны в чате |
| Калькулятор «под ключ» | Mini App (+ `/calc` в боте) | смета — таблица, а не сообщение |
| AI-диалог | только бот | ТЗ §5.8: «не дублировать Mini App» |
| Оплата, уведомления | бот | инвойс и настройки — нативные для Telegram |

Кнопка AI-разбора на карточке ведёт в чат (`t.me/<bot>?start=listing_<id>`),
потому что квота и LLM живут на бэкенде под `X-Internal-Token`, а в браузер
внутренний ключ попасть не должен.

## 2. Экраны

**Каталог.** Карточки: превью, марка-модель, год · пробег · топливо, цена
(для KRW — ещё и `≈ $` по курсу), шеврон. Пагинация по 12, кнопка «Показать ещё».
Бейдж `MOCK` в шапке показывает текущий режим — видно, что данные фикстурные.

**Карточка.** Галерея со свайпом и счётчиком `📷 2/3`, заголовок, цена, сетка из
8 спеков (год, пробег, топливо, КПП, привод, кузов, объём, цвет), три действия:
«Рассчитать доставку» (primary), «AI-анализ в боте», «Открыть у источника».
На этом экране таббар скрыт — иначе CTA уходит под него и не нажимается.

**Подбор по цене.** Четыре чипа-диапазона, поля min/max, кнопка «Показать».
Выдача сортируется по возрастанию цены, есть пустое состояние с подсказкой.

**Расчёт.** Цена/объём/год, переключатель РФ/РБ, смета по компонентам и итог.
Если пришли с карточки — поля уже заполнены и расчёт запускается сразу.

## 3. Архитектура

```
Telegram / браузер
        │  GET /          → static/index.html, app.css, app.js
        │  GET /api/*     → miniapp-service проксирует в backend-service
        ▼
miniapp-service (FastAPI)  ──HTTP──►  backend-service (:8000/8010)
        static/ + proxy                  те же /api/*, что у auto_bot
```

- **Один origin.** Статика и API на одном адресе → нет CORS, нет предзапросов,
  нет проблем с cookie-политиками WebView.
- **Прокси «тупой».** Ничего не добавляет и не подменяет: путь, query и тело
  уходят как есть. Внутренний ключ в браузер не попадает (есть тест).
- **Только публичные ручки:** `GET /api/listings`, `GET /api/listings/{id}`,
  `POST /api/calc/delivery`. Этого достаточно для всех четырёх экранов.
- **Без сборки.** Три файла статики, ES2019, никаких зависимостей и `node_modules`.
  Плюс: правится на месте, деплоится как есть; минус: нет компонентного
  переиспользования — для четырёх экранов это оправдано.

### Интеграция с Telegram

- `telegram-web-app.js` подключается, но **тема применяется только внутри
  клиента**: SDK вне Telegram всё равно вставляет свою светлую палитру, поэтому
  вне клиента принудительно тёмная схема (иначе демо в браузере выглядело белым).
- `ready()`, `expand()`, `BackButton` (показывается только на карточке),
  `HapticFeedback.impactOccurred` на тапах, `themeChanged` → переключение темы.
- Адреса экранов в hash: `#/catalog`, `#/card/12`, `#/price`, `#/calc`.
  Это даёт deep-link на лот и позволяет проверять экраны без кликов.

## 4. Как запустить

```powershell
.\make.ps1 dev              # backend :8010 + miniapp :8080 одной командой
# или по отдельности
.\make.ps1 up-backend       # :8000
.\make.ps1 up-miniapp       # :8080, проксирует в BACKEND_URL
```

Docker: `docker compose --profile miniapp-only up --build` (профиль поднимает
`backend` + `miniapp`). Для compose нужен `.env` (шаблон — `.env.example`).

Открыть: `http://127.0.0.1:8080/`.

**Чтобы бот показал кнопку**, нужен публичный HTTPS: Telegram принимает
`web_app`-кнопки только по HTTPS с валидным сертификатом. Поднимите edge:

```powershell
$env:TLS_MODE = "tunnel"
$env:TUNNEL_PROVIDER = "tunnelmole"
.\make.ps1 up-edge-tunnel      # напечатает https://…tunnelmole.net
```

Полученный адрес передайте боту как `MINIAPP_URL` и перезапустите его — кнопка
меню станет `web_app`. Другой путь — Let's Encrypt по домену, см. `docs/EDGE.md`.

## 5. Чем проверено

| Проверка | Инструмент | Результат |
|---|---|---|
| Вёрстка на телефоне | puppeteer-core, viewport 390×844, DSF 2 | `innerWidth=390`, `cardWidth=358`, `scrollWidth=390` — переполнения нет |
| Все четыре экрана | скриншоты + чтение PNG | каталог, карточка, подбор, расчёт — см. `docs/screens/` |
| Переходы | puppeteer: клик по карточке, CTA, чип, таббар | работает, включая автозапуск расчёта с карточки |
| Прокси | `tests/test_miniapp.py` (httpx.MockTransport) | путь, query, тело, 503 при недоступном бэкенде |
| Изоляция ключа | тест по исходникам статики | в `app.js`/`index.html` нет внутреннего заголовка |
| Публичные ручки | тест | в клиенте нет `/api/bot/`, `/api/dialog/`, `/api/payments/`, `/api/admin/` |

Найдено и исправлено в процессе проверки:

1. **Тема.** SDK вне Telegram навязывал светлую палитру — приложение выглядело
   белым. Введён флаг «внутри клиента».
2. **CTA под таббаром.** На карточке кнопка «Рассчитать доставку» оказывалась под
   фиксированным таббаром, и клик попадал в «Подбор». Таббар скрывается на
   карточке.
3. **Двойной путь рендера.** Переход «карточка → расчёт» рендерил экран напрямую,
   минуя `render()`, поэтому таббар оставался скрытым. Оставлен один путь.
4. **Локализация.** Цвета (`black` → «Чёрный»), дробная запятая (`2,2 л`),
   валюта KRW без символа `₩` (в части шрифтов он превращается в «тофу»).

### Чего не проверял

- **Внутри Telegram.** Скриншоты и клики — в Chrome с эмуляцией мобильного
  viewport. Реальный WebView (iOS/Android) не запускался: нужен HTTPS-адрес.
- **Реальные фото.** У фикстур синтетические URL, поэтому на скриншотах —
  SVG-заглушки по типу кузова. С настоящими источниками подставятся фото.
- **Авторизация.** Mini App не логинит пользователя: данные публичные, избранное
  и «мои фильтры» не реализованы (это Этап 4 вместе с `initData` → JWT).

## 6. Что дальше

1. **HTTPS + `setChatMenuButton(web_app=…)`** — чтобы кнопка открывала приложение
   внутри Telegram, а не в браузере.
2. **`initData` → JWT** на бэкенде: `POST /api/auth/telegram`, экран «Избранное»,
   «Мои фильтры», персональная лента.
3. **Общие токены дизайна** с ботом: сейчас палитра задана в `app.css`, тексты — в
   `skin/deutsche.py`. Имеет смысл вынести словарь строк в один JSON и отдавать
   его и боту, и Mini App.
4. **Кэш каталога** (service worker) — при возврате в приложение лента не должна
   мигать скелетонами.
